## 🎤 3. Interview Talking Points (How to Ace Technical Questions)

1. **"Why did you choose FastAPI over Flask or standard script?"**
   - *Answer:* "FastAPI provides asynchronous concurrency with Python 3.12's `asyncio`, high throughput via ASGI/Uvicorn, automatic OpenAPI/Swagger documentation, and native data validation using Pydantic. This allowed me to keep command dispatch latency under 200ms."

2. **"How does the speech recognition work across devices?"**
   - *Answer:* "I implemented a hybrid dual-engine strategy. On the web frontend, it uses the browser's native Web Speech API (`SpeechRecognition` and `SpeechSynthesis`) which requires no external drivers and works instantly on mobile or desktop. On the server or local CLI, it integrates Python's `speech_recognition` and `pyttsx3` for native desktop control."

3. **"How did you build the audio visualizer?"**
   - *Answer:* "I used the HTML5 Web Audio API to create an `AudioContext` and an `AnalyserNode` connected to the microphone input stream. The FFT frequency bin data is sampled every animation frame via `requestAnimationFrame` and drawn to an HTML5 Canvas as glowing frequency bars, with an algorithmic sine-wave fallback when idle."
